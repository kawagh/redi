## What it does

<CardGrid>
  <Card title="CLI" icon="seti:powershell">
    Read and write issues, wiki pages, time entries and news from the shell.
    Missing arguments are asked interactively, but every command can also be
    driven by flags alone so that CI and agents can use it.
  </Card>
  <Card title="TUI" icon="laptop">
    `redi --tui` opens a terminal UI for browsing and editing issues.
  </Card>
</CardGrid>
