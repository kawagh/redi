`redi --tui` opens a terminal UI. Below is that screen, running in your browser.

<TryTui lang="en" />

The data is the same sample project the demo recordings use — 18 issues, a few time
entries and three wiki pages.

## What to try

| Key | |
| --- | --- |
| `j` / `k` | Move through the list. The right pane follows |
| `Tab` | Switch between Issues, Time entries and Wiki |
| `/` | Search. Type, then `Enter`. `Esc` clears it |
| `f` | Open the filter (status, assignee, tracker, saved queries) |
| `?` | Help for the current tab |
| `Enter` | On the Wiki tab, load the page body |
| `q` | Quit |

The Wiki tab is worth a look: the body is not fetched until you press `Enter`, which is
how the real TUI keeps the tab responsive.

See [TUI](/redi/tui/) for the full key list and screenshots of the real thing.
