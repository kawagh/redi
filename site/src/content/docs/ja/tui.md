```sh
redi --tui
```

1件を調べるだけならコマンドラインで十分ですが、閲覧・作成・更新を連続して行いたい場合は
TUI での起動が便利だと思います。チケットとそのコメント、紐づく作業時間を行き来しながら
書き換えられます。

![TUI demo](https://raw.githubusercontent.com/kawagh/redi/main/doc/demo.gif)

## タブ

`Tab` / `Shift-Tab` で切り替わる3つのタブがあります。

- **チケット**
- **Wiki**
- **作業時間**

## キー操作

**基本的に vim 風のキーバインドです。** `j` / `k` で移動し、`gg` / `G` で先頭・末尾へ、
`/` で検索します。

そのタブで使えるキーは、画面下のステータスバーに常に出ています。

```text
jk:move /:search f:filter p:project c:create u:update v:web ?:help q:quit
```

`?` を押すとそのタブのヘルプが開きます。よく使うものだけ挙げます。

| キー | |
| --- | --- |
| `j` / `k` | 下 / 上に移動 |
| `gg` / `G` | 先頭 / 末尾へ |
| `Ctrl-d` / `Ctrl-u` | 半画面 下 / 上 |
| `Enter` | 選択中の項目を開く |
| `/` | 一覧内を検索 |
| `n` / `N` | 次 / 前の一致へ |
| `f` | フィルタ |
| `p` | プロジェクトを切り替える |
| `c` | 作成 |
| `u` | 更新 |
| `D` | 削除 |
| `v` | ブラウザで開く |
| `?` | 現在のタブのヘルプ |
| `q` | 終了 |
