`redi --tui` で開くターミナル UI を、そのままブラウザ上に置いています。

<TryTui lang="ja" />

データはデモの収録で使っているサンプルプロジェクトと同じもので、18 件のイシューと
作業時間、3 ページの Wiki が入っています。

## 試せること

| キー | |
| --- | --- |
| `j` / `k` | 一覧を移動します。右ペインが追従します |
| `Tab` | イシュー / 作業時間 / Wiki を切り替えます |
| `/` | 検索します。入力して `Enter`、`Esc` で解除 |
| `f` | 絞り込み (ステータス / 担当者 / トラッカー / クエリ) を開きます |
| `?` | 現在のタブのヘルプ |
| `Enter` | Wiki タブでページの本文を読み込みます |
| `q` | 終了 |

Wiki タブが分かりやすいと思います。本文は `Enter` を押すまで取得しません。実物の TUI が
タブの応答を保つためにそうしている挙動です。

キーの一覧と実物のスクリーンショットは [TUI](/redi/ja/tui/) にあります。
